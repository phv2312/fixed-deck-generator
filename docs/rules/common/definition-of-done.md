# Definition of Done

Before you mark a change as complete, run the checks of each area that you changed.

1. Read the `Checks` section in [common/README.md](./README.md) and in the README of each area that you changed.
2. Run each command and each check. Fix each failure.
3. Confirm the non-negotiable rules in [../README.md](../README.md).
4. Update the documents that the change affects.
5. Do not commit when a check fails.

When a change touches more than one area, run the checks of all of them. When no area applies, run the tests of the project.
