# Slide catalog

`scripts/gen_catalog.py` generates these pages from the builder registry. Each family page shows its slides with a preview, the LLM-facing description, and the parameters that an LLM must supply.

Do not edit these pages. Change the builder or the spec model, then run the generator again.

| family | description | slides |
|---|---|---:|
| [analytics](analytics.md) | Charts and data-driven slides. | 4 |
| [body](body.md) | Text, table, key-figure and terminal slides. | 7 |
| [decisions](decisions.md) | Options, assessments and decisions. | 7 |
| [diagram](diagram.md) | Process and concept diagrams. | 12 |
| [layout](layout.md) | Opening, divider, agenda, text and closing slides. | 6 |
| [pictures](pictures.md) | Slides built around a picture. | 2 |
| [programme](programme.md) | Plans, timelines and project status. | 5 |
